LABEGE - Interactive Physics Laboratory

Run locally:
1. Extract this ZIP into a folder.
2. Open index.html in a current browser (Chrome, Edge, Firefox, Safari).

Included independent model demos:
- Mechanics: accelerated motion; kinetic and potential energy.
- Electricity: Ohm's law circuit.
- Optics: refraction.

Notes:
- Each model is opened in its own modal and has its own parameter set/time state.
- The energy model resets animation time when a parameter is adjusted.
- The layout has a mobile responsive breakpoint.
- This package was checked with JS syntax and a mocked DOM/Canvas smoke test. Full visual browser testing was not completed.
