LABEGE - Interactive Physics Laboratory

Open index.html in a current browser (Chrome, Edge, Firefox, or Safari).

The site contains 60 interactive models:
- Mechanics: kinematics, dynamics, statics, oscillations and conservation laws.
- Electrodynamics: circuits, electrostatics, magnetic fields, and induction.
- Optics: reflection, refraction, lenses, mirrors, and dispersion.
- Thermodynamics: MKT, gas processes, heating, phase changes, heat balance, combustion and efficiency.

Each model has parameters, formulas, calculated results, and Canvas visualizations.
The statics section includes force balance and first-class and second-class levers.
Thermodynamics includes selectable substances and transition temperatures at standard pressure.
The layout supports mobile screens.

Rounded thermodynamic reference values are based on OpenStax Physics and NIST Chemistry WebBook data; phase transition temperatures assume standard atmospheric pressure. Fuel heating values are approximate lower heating values.
